# تصحيح — Tashih AI

**تحقّق من الحديث قبل أن تنشره.** تكتب نص الحديث فيعيد لك «تصحيح» ثلاثة أشياء: **الحكم**، و**من حكم عليه**، و**المصدر**.

مشروع مشارك في «تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي» — مسار «الحوار المعرفي والإجابات الموثقة».

## المبدأ الذي بُني عليه المشروع

- **الحكم يأتي من المصدر الحديثي دائماً، وليس من النموذج اللغوي.** رمز الحكم يُحسب بكود ثابت من نص حكم المحدِّث.
- إذا لم يُعثر على النص بثقة كافية، يجيب النظام بـ `not_found` ويمتنع عن الحكم ويحيل إلى أهل العلم. لا يخترع حكماً ولا مصدراً ولا راوياً.
- النموذج اللغوي اختياري، ودوره محصور في أمرين: استخراج نص الحديث من رسالة المستخدم، وصياغة شرح مبسط للنتيجة الموجودة. مخرجاته تُفحص بالكود وتُحذف إذا خالفت الحكم.
- الحديث الضعيف أو الموضوع يُذكر معه صراحةً أنه لا ينبغي نسبته إلى النبي ﷺ.
- **يتحمّل أخطاء الكتابة دون تخمين:** مسافة في غير موضعها أو حرف ناقص أو زائد في الكلمة لا يمنع العثور على الحديث، ومعه تنبيه بأن المطابقة ليست حرفية. نص مختلف لا «يُصحَّح» إلى حديث آخر.
- أحكام المحدثين قد تختلف، لذلك تُعرض كل الأحكام المتاحة، ولا يُقدَّم حكم محدِّث واحد على أنه إجماع. وإذا انقسم المحدثون بين قبول وردّ فالحكم المعروض «مختلف فيه» مع ذكر الفريقين. وما كان في صحيح البخاري أو صحيح مسلم فهو صحيح بمصدره.

## المكوّنات

| المكوّن | الوصف |
| --- | --- |
| **FastAPI** (`app/`) | المنتج الفعلي: واجهة برمجية موثقة بإصدار `v1` يبني عليها تطبيق Flutter |
| **Streamlit** (`ui/`) | واجهة عرض تجريبية بالعربية: محادثة التحقق + تبويب الصلاة |
| **المصادر** | الدرر السنية (المصدر الأساسي) ثم الكتب الستة من قاعدة بيانات مفتوحة (احتياطي يعمل بلا إنترنت بعد أول تشغيل) |
| **رفيق يومي** | مواقيت الصلاة، القبلة، نوافذ التركيز وقت الصلاة (لقفل التطبيقات المشتتة في تطبيق الجوال)، وحديث اليوم من الصحيحين |

## التشغيل السريع (Docker)

```bash
cp .env.example .env        # اختياري: ضع OPENAI_API_KEY لتفعيل الشرح المبسط
docker compose up --build -d
```

- الواجهة التجريبية: <http://localhost:8501>
- الـ API وتوثيقه التفاعلي: <http://localhost:8000/docs>
- الحالة: <http://localhost:8000/health>

عند أول تشغيل تُحمَّل قاعدة الكتب الستة (نحو 40 ميغابايت) وتُحفظ في volume، فيظهر `offline: loading` لمدة قصيرة ثم `ready`.

## التشغيل بدون Docker

يحتاج Python 3.12.

```bash
python -m venv .venv
.venv\Scripts\activate            # على Linux/macOS: source .venv/bin/activate
pip install -r requirements-dev.txt

python -m uvicorn app.main:app_factory --factory --reload --port 8000   # الـ API
python -m streamlit run ui/app.py                                       # الواجهة
```

## تجربة سريعة

```bash
curl -s http://localhost:8000/v1/verify -H "Content-Type: application/json" \
  -d '{"text": "اطلبوا العلم ولو في الصين"}'
```

أو شغّل كل الأمثلة دفعة واحدة:

```bash
python -m scripts.demo_requests http://localhost:8000
```

| الإدخال | النتيجة |
| --- | --- |
| إنما الأعمال بالنيات | صحيح — صحيح البخاري رقم 1 |
| انماا لاعمال بالنيات هو دا حديث صحيح | صحيح — نفس الحديث، مع تنبيه أن المطابقة ليست حرفية |
| الدين النصيحة | صحيح — صحيح مسلم |
| طلب العلم فريضة على كل مسلم | ضعيف (حكم أغلب المحدثين في النتائج) |
| اطلبوا العلم ولو في الصين | ضعيف (ابن باز) |
| حب الوطن من الإيمان | موضوع (مكذوب) |
| لا ضرر ولا ضرار | مختلف فيه — مع ذكر من قبِله ومن ردّه |
| سمعت حديث بيقول النضافة من الايمان ايه صحته | ضعيف — بعد تصحيح الإملاء بالذكاء الاصطناعي إلى «النظافة من الإيمان» |
| جملة مختلقة | `not_found` — يمتنع عن الحكم |

إذا تعذر الوصول إلى الدرر السنية يجيب النظام من الكتب الستة فقط (مثلاً «إنما الأعمال بالنيات» ← صحيح البخاري رقم 1)، ويذكر ذلك في الرد.

## نقاط الواجهة البرمجية

| المسار | الوظيفة |
| --- | --- |
| `GET /health` | حالة الخدمة والمصادر |
| `POST /v1/verify` | التحقق من نص حديث |
| `POST /v1/chat` | محادثة: تحديد المقصود + التحقق + رد جاهز للعرض |
| `GET /v1/prayer/times` | مواقيت الصلاة والتاريخ الهجري والصلاة القادمة |
| `GET /v1/prayer/qibla` | اتجاه القبلة |
| `GET /v1/prayer/focus-schedule` | نوافذ التركيز حول كل صلاة |
| `GET /v1/daily` | بطاقة اليوم: حديث من الصحيحين + الصلاة القادمة |

التفاصيل الكاملة لفريقي الـ backend و Flutter في [`docs/API.md`](docs/API.md)، والمخطط الآلي في [`docs/openapi.json`](docs/openapi.json).

## الإعدادات

كل المتغيرات مشروحة في [`.env.example`](.env.example). أهمها:

| المتغير | الافتراضي | الوصف |
| --- | --- | --- |
| `SOURCES` | `dorar,offline` | ترتيب المصادر |
| `OPENAI_API_KEY` | فارغ | بدونه يعمل كل شيء عدا الشرح المبسط |
| `API_KEYS` | فارغ | مفاتيح `X-API-Key` (فارغ = بلا مصادقة) |
| `RATE_LIMIT_PER_MINUTE` | `60` | حد الطلبات لكل عنوان IP |
| `CORS_ORIGINS` | `*` | النطاقات المسموح لها |

## حدود معروفة

- موقع الدرر السنية خلف Cloudflare وقد يحجب بعض الخوادم السحابية؛ عندها ينتقل النظام تلقائياً إلى الكتب الستة ويذكر ذلك في الرد. التفاصيل في [`docs/API.md`](docs/API.md).
- واجهة الدرر تعيد 15 نتيجة فقط لكل بحث، فقد لا تظهر كل أحكام المحدثين على الحديث.
- المصنِّف الآلي للأحكام متحفّظ: العبارة التي لا يتعرف عليها تُعرض كما هي مع الوسم «يحتاج مراجعة».
- قفل التطبيقات وقت الصلاة ينفَّذ في تطبيق الجوال؛ الخادم يحسب الجدول فقط.

## تنبيه

«تصحيح» أداة مساعدة تنقل أحكام المحدثين من مصادرها، وليست بديلاً عن أهل العلم. للفتوى والمسائل الشرعية راجع أهل العلم.
